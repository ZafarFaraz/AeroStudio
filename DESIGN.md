# AeroStudio visual system

The product uses an efficient dark classroom-workbench interface: near-black navy canvas, layered blue-grey surfaces, cyan focus and primary actions, green safety feedback, and red reserved for emergency actions. The existing geometric drone mark and program illustrations remain the visual identity.

The shell has a compact top connection bar, a persistent task sidebar on wide screens, one dominant working surface, and a flight-updates strip that remains visible. Typography uses the system UI stack and system monospace for code. Controls have modest radii, visible borders, clear focus rings, and at least 44px touch targets. Avoid marketing heroes, glass effects, gradients, excessive pills, decorative motion, and dense technical language.

Responsive behavior turns the sidebar into a horizontal tab rail and stacks split workspaces. Motion is limited to state changes, selection, connection progress, and reduced-motion-safe feedback.
